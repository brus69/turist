# HTML-шаблоны туристического сайта-агрегатора (Django)

Публичный сайт рендерится **Django Templates** из каталога `backend/templates/`. Отдельного фронтенд-проекта нет.

Соответствие макетов и файлов:

| Макет (условное имя) | Шаблон |
|---------------------|--------|
| Главная | `home.html` |
| Каталог туров | `tours/catalog.html` |
| Карточка тура | `tours/detail.html` |
| Общая обёртка | `base.html` |
| Карточка в списке | `partials/tour_card.html` |

## Главная (`home.html`)

- Верхнее меню
- Блок hero: подложка / слайдер, по центру «Агрегатор походов по всей РФ», форма поиска тура (когда, куда, вид активности), кнопка «выбрать тур»
- Блок ближайшие даты
- Блок виды активности
- Направления
- Фото поездок
- Почему мы
- Отзывы
- Статьи
- Футер

## Каталог (`tours/catalog.html`)

- Верхнее меню
- Хлебные крошки
- Заголовок
- Поиск: дата, сложность, стоимость (и прочие фильтры каталога)
- Сетка туров (карточки через `partials/tour_card.html`)

## Карточка тура (`tours/detail.html`)

- Верхнее меню
- Фотографии, блок «куда пойдём»
- Две колонки: широкая — описание тура; узкая — цена, выбор даты, заявка, инструктор
